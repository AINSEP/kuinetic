kUInetic

A CSS animation library you author in HTML attributes.

Write data-kui="fade-up 900ms" on an element. The library compiles that string into real CSS keyframes and native scroll-driven timelines. There is no animation loop to hand a scene graph to, and for roughly seventy per cent of the catalogue there is no runtime JavaScript at all.

The Feature  ·  No. 01

A string, sitting in the markup, next to the thing it moves

Every animation on this page began as a value in an HTML attribute. Not a configuration object, not a hook, not a timeline assembled in JavaScript and handed to a renderer — a string, sitting in the markup, next to the element it moves. That is the whole authoring surface, and it is the reason the source of this page reads as a document rather than as a program.

The grammar is three positional arguments in a fixed order — duration, delay, easing — followed by named parameters. data-kui="fade-up 900ms 150ms ease-out" is the entirety of it. Effects separated by commas compose into one compiled animation.

Composition is checked rather than hoped for. Every effect declares the CSS properties it owns — its channels. Two effects whose channels are disjoint compile together into a single animation. Two that both want opacity collide, and the library says so, instead of letting one quietly overwrite the other.

Of the two hundred and fifty-two names, roughly one hundred and sixty-eight are keyframes and a metadata row and nothing else. About fifty-eight need genuine per-frame JavaScript. Twelve do a single piece of DOM preparation and then hand the work back to CSS.

Scroll-linked effects run on native CSS scroll-driven timelines where the browser has them, and fall back to one shared JavaScript orchestrator where it does not. Text splitting uses Intl.Segmenter, so it counts grapheme clusters rather than code units, preserves one accessible reading of the text throughout, and restores selectable text when it cleans up.

Forty-eight of the names come from a single family — the entrance and exit matrix — so the count is a vocabulary, not a measure of how much code there is.

Roughly seventy per cent of the catalogue is keyframes plus a metadata row.

In This Issue  ·  No. 04

Nine pages, each one a working demonstration

I Reveals Entrance, composition, parameter and trigger patterns — compiled to real CSS keyframes, zero animation-loop JavaScript. II Scroll Parallax, progress, pinning, scrollytelling and horizontal scroll — native timelines where the browser has them, a shared orchestrator where it does not. III Interactive Drag, throw, swipe, magnetic pull, long-press and FLIP-powered layout transitions, driven by a spring integrator rather than keyframes. IV Text Twenty-six typographic primitives — segmentation, typing, resolve, colour, variable font and structural effects — with one accessible reading preserved throughout. V Data & Hover Counters, SVG progress geometry and rating fills, beside button, border, link, icon, card-tilt and cursor effects — one attribute each. VI Ambient & Feedback Gradients, noise, scanlines, spinners, toasts and click reactions — continuous backgrounds and event-driven responses, compiled to real CSS. VII Nav & Forms Eight navigation primitives and twelve form primitives, where the library owns only the motion — never the open state, and never focus handling. VIII Icons & Transitions Every SVG draw, fill, morph and icon toggle in catalogue section E, plus section L's page transitions. Unlisted in the site navigation IX 3D & Perspective Card flips, cube rotation, page turns and folding panels — real CSS keyframes behind a perspective transform. Unlisted in the site navigation

Colophon

Two files, and one attribute

Installation
Two files. No build step, no bundler configuration. A CDN pair or an import from a bundler both work unchanged.
Catalogue
255 named effects over more than 31 primitive families, in fifteen sections lettered A to O, plus thirteen gesture and physics names outside them.
Renderers
Approximately 168 CSS, 12 preparation, 58 JavaScript.
Out of scope
WebGL and particle rendering, and accessible component state machines. The library animates elements you control; it never owns their open state, their focus, or their keyboard handling.
Type
Set in the reader's own Didot or Bodoni for display, an old-style book serif for reading, and a single letterspaced grotesque for every caption. No web fonts are requested by this page.
Plates
Photography from this repository's own asset library.
