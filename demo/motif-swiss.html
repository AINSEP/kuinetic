CSS animation library — authored in HTML Fig. 01 / Release 0.1.3 / MIT

One attribute. 255 effects. No build step.

kUInetic is a CSS animation library you author in HTML. You write one attribute on an element — data-kui="fade-up 600ms on:enter" — and the library compiles it into real CSS keyframes and native scroll-driven timelines. No animation code to write, no timeline objects to keep in sync with your markup.

Roughly seventy per cent of the catalogue is keyframes plus a metadata row and ships with zero runtime JavaScript on browsers with native timelines. JavaScript runs only for the names that genuinely need it — morphs, scrubs, counters, pointer physics.

The whole API, printed once

<div data-kui="fade-up 600ms 100ms steps(6,end) on:enter">
Namefade-up
Timing600ms 100ms steps(6,end)
Triggeron:enter

Note

Positional, always in that order. Comma-separate two effects and they compile into one animation — unless they claim the same CSS property, which the library refuses rather than letting one silently overwrite the other.

01The grammar

Three parts. That is the whole language.

01  Name

data-kui="wipe-right"

255 named effects across 31 primitive families. Every name is a real entry in the catalogue — nothing is composed at runtime out of adjectives.

02  Timing

"wipe-right 420ms 60ms linear"

Duration, delay, easing — positional, in that order. Keywords, steps() and cubic-bezier() all parse. Everything on this page is a steep bezier or a step function.

03  Trigger

"wipe-right on:hover"

Defaults to on:enter — it plays when the element scrolls into view. Swap for hover, click, focus or manual.

02Live

Rewrite the attribute. Watch it recompile.

One element. One attribute. Each cell below writes a different value onto the same frame and the runtime recompiles it in place — no rebuild, no re-render, nothing else on the page touched.

data-kui="wipe-circle 700ms 0ms cubic-bezier(.85,0,.15,1)"

04Install

Two files. No build step. No bundler config.

<!-- 1. the stylesheet and the runtime -->
<link rel="stylesheet" href="kuinetic.css">
<script src="kuinetic.js"></script>
<script>
  kuinetic.kuinetic({ observe: true }).start()
</script>

<!-- 2. write one attribute -->
<h1 data-kui="fade-up">Hello.</h1>

01  Two files

A stylesheet and a runtime. Nothing else — the package declares no dependencies.

02  observe: true

Keeps a MutationObserver running so elements added later — by your app, a CMS, a client-side router — get picked up on their own.

03  Then write markup

Everything after that is an attribute. There is no second API to learn before the first animation runs.
