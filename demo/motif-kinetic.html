Write Motion In HTML

kUInetic compiles HTML attributes into real CSS keyframes and native scroll-driven timelines. One element, one attribute — data-kui="fade-up" — and no JavaScript for you to write.

255 named effects over 31 primitive families. Roughly 70% of the catalog is keyframes plus a metadata row, and ships with zero runtime JS on browsers with native timelines.

The whole API, live

Click a name. Watch it change.

One element, one attribute. Every chip below writes a different value onto the same frame and the browser recompiles it — no rebuild, no re-render, nothing else on the page touched.

Comma-separate two effects whose channels don't overlap and they compile into one declaration. Two that want the same CSS property collide, and the library says so in the console instead of letting one quietly win.

data-kui="wipe-circle 1500ms"

Install

No build step.

Two files and no bundler config. observe: true keeps a MutationObserver running, so elements added later — by your app, a CMS, a client-side router — get picked up automatically.
